yt-dlp Workbench · reUI
Supported system: Windows 10 22H2 / Windows 11 x64
Project: https://github.com/Yes-nolink/ytdlp-interface-reUI

English guide: https://github.com/Yes-nolink/ytdlp-interface-reUI/blob/main/README.en.md

1. Install and launch
Download the windows-x64-setup.exe installer and follow the setup wizard.
yt-dlp, FFmpeg, ffprobe, and Deno are included. Python is not required.
A missing WebView2 Runtime is installed using Microsoft's bundled offline installer.
Setup works offline; extracting links and downloading media require internet access.
Launch reUI from the desktop or Start menu and choose an output folder.
Default install folder: %LOCALAPPDATA%\Programs\ytdlp-interface-reUI
Component versions, sources, and checksums are recorded in licenses\components.json.

2. Start downloading
Paste video, playlist, or channel links into the workbench and click Parse links.
Choose entries, then select output format, quality, and a destination folder.
Adjust subtitles, artwork, metadata, and file naming as needed.
Add the selection to the queue or start downloading.
Use Download tasks to inspect progress, logs, and output files.

3. Language and settings
The sidebar provides Download defaults, Tasks and scheduling, Network and authentication,
Components and updates, Appearance and app, Advanced and presets, and About.
Switch language under Appearance and app, then restart.
User preset names, file names, and download settings are preserved.

4. Updates and data
Check for component updates before updating. The installer includes the components
needed for first use; Deno can also be installed in the app.
GUI auto-update is disabled. Obtain new installers from this repository's Releases,
close the app, then install into the same folder.
Default user data is stored under %LOCALAPPDATA%\ytdlp-interface.
Uninstall through Windows Installed apps. Personal data, downloaded media, and the
shared WebView2 Runtime are kept.
Old Nana queues cannot be imported, and legacy custom themes are not supported.
